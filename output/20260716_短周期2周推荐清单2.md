## 五、专业知识点

| 概念 | 解释 |
|:---:|:---|
| **入场优势(entryEdge/entryScore)** | 技术面量化评分(0-25分),衡量当前价位是否处于好的入场时机。>=18为好价格,12-17为合理,<12为追涨风险。九洲药业教训:入场优势<12/25的追涨票不得排Top1 |
| **回测环境分层** | 将3月历史K线按市场环境(顺风/震荡/逆风)分层统计胜率,避免单一市场环境下回测结论偏差。华兰生物顺风WR=60%+震荡WR=50%说明有正期望 |
| **催化兑现度** | 催化事件是否已被股价消化(price-in)。未price-in=好时机;半兑现=部分消化;已透支=完全消化甚至过度。永安药业m5=30.75%=已透支 |
| **动量质量(momentumQuality)** | 衡量涨幅是均匀分布(4/5日涨,健康)还是单日暴涨撑数据(不健康)。华兰生物timing=4.0为全组最高,说明4/5日均匀涨+量价配合 |
| **催化同源<=50%** | 组合中来自同一催化源(如同一政策)的标的仓位合计不超过50%,防止单一催化兑现后组合集体回调 |
| **驰宏锌锗回测纪律** | 回测3项(胜率>=55%/均收>=2%/回撤<=8%)全不达标的标的不得入TopN,不得排Top1给最大仓位。本期华兰生物回撤-7.93%达标,observation级 |
| **PE历史分位** | 当前PE在过去5年中的百分位,越低越便宜。本期因iFind SSL故障无法获取,仅用绝对PE判断 |
| **T+1涨跌停** | A股当日买入次日方可卖出(T+1),涨停板10%(创业板/科创板20%)。影响止损执行和追涨风险 |
| **1w账户手数约束** | 最小交易100股(1手),股价>100元则1手>1万元无法配置。本期Top4均<40元,1手<4000元 |
