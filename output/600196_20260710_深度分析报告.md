## 七、专业知识点

| 概念 | 说明 |
|------|------|
| **PE 历史分位** | 当前 PE 在近 5 年所有交易日中的排名百分位,11% 意味着比 89% 的时间都便宜 |
| **OCF/NI(经营现金流/净利润)** | 衡量盈利含金量,>1 表示利润有真金白银支撑,1.55 为优秀水平 |
| **多头排列** | MA5 > MA10 > MA20,短中长期均线依次排列,表明上升趋势确立 |
| **杜邦分析** | ROE = 净利率 x 资产周转率 x 权益乘数 = 8.1% x 0.35 x 1.94 = 7.03% |
| **催化兑现度** | 催化事件是否已被市场定价(price-in),未兑现的催化才有交易价值 |
| **回测纪律** | 胜率 >= 55% / 均收 >= 3% / 回撤 <= 8%,3 项至少 2 项达标方可保留(驰宏锌锗教训) |
| **流动性硬门槛** | 20 日均成交 >= 1 亿 / 换手 1%-7% / 流通市值 >= 30 亿,不过关直接剔除 |
| **T+1 涨跌停** | A 股当日买入次日方可卖出,涨跌停板 10%,操作须考虑次日开盘风险 |
| **1w 账户手数约束** | 100 股最小交易单位,23.45 元/股 x 100 = 2345 元/手,最多 4 手 |
