## 五、专业知识点

| 概念 | 说明 |
|---|---|
| **回测环境分层** | 将18周回测窗口按市场环境分为tailwind(顺风)/neutral(中性)/headwind(逆风),避免单一胜率被极端环境扭曲。当前neutral环境胜率更具参考价值 |
| **入场优势(timing_score)** | 综合均值回归信号+动量质量+透支概率,≥12为好入场,<10为G3强制观察。海康威视timing=1.8为中性,非好入场 |
| **G5(composite<0不得Top1)** | 因子引擎综合分<0意味着该标的在七维因子(z-score加权)中处于后50%,不得排Top1但可排Top2-5 |
| **G6(MCP全挂)** | 当iFind/Wind/AkShare MCP全部不可用时,财务数据仅依赖腾讯HTTP(PE/PB/市值),置信度强制"低",总仓位≤40% |
| **催化兑现度** | 近5日涨幅>15%为半兑现(需降权),>30%为已透支(剔除)。海康威视近5日+8.6%未触发预警 |
| **驰宏锌锗纪律** | 回测证伪的标的不得强推——本次000815(美利云)和688709(成都华微)回测rejected,严格执行一票否决 |
| **T+1/涨跌停** | A股T+1交收+10%涨跌停板,2周周期内需考虑停板流动性风险,100股最小手数约束1w账户仓位 |
