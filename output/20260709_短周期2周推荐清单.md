## 3. 专业知识点

| 概念 | 含义 |
|---|---|
| **催化兑现度** | 催化事件对股价的反映程度。未price-in=尚未反映,短线催化空间大;已透支=提前反映过多,追高风险大 |
| **驰宏锌锗纪律** | 回测证伪不得强推/财务否决优先于催化排名/盘中价不作买入依据。源于此前推荐失误教训 |
| **m20(20日涨幅)** | 距20日均线的偏离幅度。>15%为中期透支,>30%为严重透支,>50%为极端透支(流动性硬门槛剔除) |
| **RPS(相对价格强度)** | 0-100,衡量个股在全市场的相对强度排名。100=最强,0=最弱 |
| **OCF/NP** | 经营现金流/净利润。>1x说明利润有现金支撑,非纸面利润。京东方8.33x极优 |
| **催化同源<=50%** | 组合中来自同一催化逻辑的标的占比不超过50%,避免板块回调时全军覆没 |
| **回测三阈值** | 胜率>=55%/均收>=3%/回撤<=8%,三项全达标方可入TopN;全不达标不得入TopN |
| **T+1/涨跌停** | A股当日买入次日方可卖出(T+1);科创板涨跌停20%,主板10% |
| **1w账户手数约束** | 100股最小交易单位,股价23.49元-->1手=2349元占1w账户23.5%,无法精细调仓 |
