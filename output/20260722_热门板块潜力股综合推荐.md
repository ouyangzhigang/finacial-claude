## 专业知识点

| 概念 | 解释 |
|---|---|
| **趋势市(regime)** | 市场处于单边运动(当前下跌),动量因子权重提升至1.5x,顺势而为而非逆势抄底 |
| **pullback_buy** | 回调买入策略:在下跌趋势中,等股价回调至支撑位再入场,而非追涨 |
| **一票否决(回测纪律)** | 回测3项(胜率>=55%/均收>=2%/回撤<=8%)全不达标→不得入TopN。源自驰宏锌锗教训:回测证伪的标的不得强推 |
| **仓位砍半规则** | 回测2项不达标→仓位砍半(原建议仓位×0.5)。粤电力A原800股→600股 |
| **置信区间(N=18)** | 18个样本的95%置信区间较宽(如粤电力A 21.5%-67.4%),真实胜率在区间内,样本量不足需标注 |
| **催化同源<=50%** | 组合中同一催化来源的仓位占比不超过50%,避免单一事件冲击。当前仅1只实盘,无此风险 |
| **exhaustionProb** | 动量衰竭概率:基于5日涨幅/波动扩张/催化天数综合判断,>70%时需警惕追涨 |
| **volumeHealth** | 量价配合健康度:粤电力A=10.02(极高),说明上涨有量能支撑,非无量空涨 |
| **T+1制度** | A股当日买入次日方可卖出,短线操作需预留1日缓冲 |
