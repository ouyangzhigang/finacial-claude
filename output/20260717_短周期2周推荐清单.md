## 专业知识点

| 术语 | 含义 |
|---|---|
| Shock regime | 市场环境分类: 急跌/恐慌型, breadth<30%, 需收紧止损+高现金 |
| 入场优势(entryEdge) | 综合估值/回调/催化未price-in的25分制评分, >=18为好价格, <12为追涨 |
| Observation级 | 回测仅1/3达标(胜率), 仓位砍半为观察性质, 非full approval |
| 催化兑现度 | m5涨幅衡量催化被市场消化的程度, <5%=完全未price-in, >15%=半兑现 |
| 驰宏锌锗教训 | 回测3项全不达标不得入TopN/不得排Top1给最大仓位 |
| 九洲药业教训 | 入场优势<12/25=追涨票, 不得排Top1给最大仓位 |
| 催化同源<=50% | 组合中来自同一催化源的仓位占比不超50%, 避免单一事件风险 |
| 动量质量 | 均匀性(uniformity 0-4)+量价配合度, 高均匀性=每天稳步涨优于单日暴涨 |
| Breakout confirmed | 技术面突破确认, entry_score +15 |
| Chasing | 追涨型入场, entry_score -15, 一票否决 |
