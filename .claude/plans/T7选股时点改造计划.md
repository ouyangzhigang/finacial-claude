# T7 选股时点改造计划：从"选当日已涨"到"预测次日将涨"

> 创建：2026-07-31
> 触发：用户反馈"昨天怎么不预测出来给我推，现在涨完了推，废物"
> 病根：workflow 是"今天跑、选今天已涨的票"，而非"前日盘后预测次日将涨"
> 目标：T-1 收盘后跑 → 预测 T 日将涨的票（还没涨、能买进）

---

## 一、病根定位（已完成）

### B1. forecast 模型是回看式，非预测
- `core/forecasting/prob_path.py`:`up_prob = logistic(composite_score) + regime_bias`
- composite_score 来自因子引擎 = 动量(m5/m10/m20) + 量价突破 + 技术位
- 这些因子全是**已发生**数据 → "今天涨得好"→ 高 up_prob → 推给你时已涨完
- 非真预测：没有"次日将涨"的信号，只有"今天已涨"

### B2. 因子引擎选"已突破"非"将突破"
- `scripts/factor_engine.py` 的 m5/m10/m20 动量、量价突破因子，衡量的是"已经涨了"
- 没有找"回踩缩量企稳/蓄势待突破/催化未兑现"的"将涨"信号

### B3. 调度错位
- 我每次都是用户发命令才跑（盘中/收盘后），选的是当天的票
- 没主动在前日盘后（15:30）跑次日预判

### B4. 候选池未过滤当日已涨停/封板票
- 已涨停的票买不进/追高，但 workflow 仍会选入（因动量高）
- sector/factor 层没过滤"当日涨幅>7%或封板"的票

## 二、改造任务

### T7.1 forecast 模型从"回看"转"预测次日"【核心】
- 文件：`core/forecasting/prob_path.py`
- 改造：
  - [T7.1.1] 加"次日将涨"预测信号：回踩MA20缩量企稳、蓄势突破前夜、催化未兑现、资金未启动
  - [T7.1.2] composite 分解为"已涨动量"（惩罚）+ "将涨信号"（奖励），让未涨但有将涨信号的票 up_prob 更高
  - [T7.1.3] 真预测目标：up_prob = P(T日涨 | T-1特征)，而非 P(今天涨 | 今天特征)
- 验证：up_prob 高的票是"今天还没涨但将涨"的，而非"今天已涨停"的

### T7.2 因子引擎加"将涨信号"因子
- 文件：`scripts/factor_engine.py`
- 改造：
  - [T7.2.1] 加"回踩买点因子"：MA20回踩缩量企稳（非已突破）
  - [T7.2.2] 加"蓄势因子"：区间震荡缩量、贴近上轨待突破
  - [T7.2.3] 加"催化未兑现因子"：有催化但当日未涨（次日可能兑现）
- 验证：因子高的票是未涨但有潜力的，而非已涨停的

### T7.3 候选池过滤当日已涨停/封板票
- 文件：`scripts/hard_gate.py` 或 sector prompt
- 改造：
  - [T7.3.1] 加新硬门 G9：当日涨幅>7% 或 封板（涨停）→ 标记"不可买入·追高"，降级或不入TopN
  - [T7.3.2] sector 撒网时优先"当日未大涨但有催化/资金"的票
- 验证：TopN 不含当日涨停/封板的票

### T7.4 调度改"前日盘后预测次日"
- 改造：
  - [T7.4.1] workflow 用 T-1 收盘数据（非 T 日盘中）预测 T 日
  - [T7.4.2] 我主动在每日收盘后 15:30 跑次日预判（用 ScheduleWakeup 或提醒用户）
  - [T7.4.3] 报告标题改为"次日预判"而非"当日推荐"
- 验证：报告日期 = T-1 跑出预测 T 日的票，T 日验证是否真涨
