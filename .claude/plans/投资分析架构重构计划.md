# 全新预判型投资分析架构设计（Future-Picks）

> 创建：2026-07-31 ｜ 状态：设计完成，待实施
> 宗旨：找未来时间段有潜力上涨的股票，且说清"为什么预判它将涨"的完整推理链
> 用户选择：全周期分层（短线1-5日 + 波段1-2周 + 中线1-3月）

---

## Context（为什么做这个）

用户痛批旧架构"跑几小时拉一堆数据，没有真正思考逻辑和分析，报告瞎扯淡糊弄"。旧 short-term-picks 的根本问题：
1. 拉数据多思考少（27文件/几十万token，final.json 只3KB/报告129行）
2. 因子是"已涨回看"（m5/m10/m20/封板率），选出"今天涨得好"的票，非"未来将涨"
3. 报告是套话模板，无"因为A→B→C→预判D将涨"的演绎推理
4. 新闻/政策/热点只打一个分，没做"利好谁→哪只票受益"的语义映射
5. agent 是数据流水线工人，无推理接力

**宗旨（唯一评判标准）**：找未来时间段真正有潜力上涨的股票，且能说清为什么。不是当日排行榜，不是数据堆砌，不是套话报告。

**约束**：新建全新架构，不复用/不影响旧 short-term-picks（旧的留存）。复用现有可用资源（技能/脚本/MCP/agent），但不给旧框架打补丁。

## 新架构设计

### 核心理念：推理链驱动，非数据流水线

旧：prefetch→撒网→过滤→打分→硬门→回测→拼报告（数据流水线，每个agent拉数据输出json）
新：**预判假设 → 证据收集 → 推理验证 → 潜力锁定 → 跟踪兑现**（推理链，每个agent输出"推理+预判"）

### 全周期分层（用户选定）

| 周期 | 预判重点 | 主因子 | 调度 |
|---|---|---|---|
| 短线1-5日 | 资金流/龙虎榜/次催化/形态突破前夜 | 主力净流入未拉升 + 蓄势突破 | 每日盘后 |
| 波段1-2周 | 板块轮动接力/催化日历/回踩买点 | 板块接力 + 催化将兑现 + 回踩缩量 | 每周 |
| 中线1-3月 | 宏观周期/业绩/产业趋势/估值修复 | 周期定位 + 业绩预增 + 估值修复 | 每月 |

### 新工作流：future-picks（三周期分层）

文件：`.claude/workflows/future-picks.js`（新建，不动旧的）

**推理链5阶段**（每阶段输出"推理+预判"，非纯数据）：

#### 阶段1：预判假设（Hypothesis）—— 定方向
- macro-strategist + sector-rotation-detector 技能
- 输入：当前 regime + 宏观指标 + 政策主线 + 地缘
- 输出：**预判未来N天占优风格 + 顺风板块 + 接力方向**（不是"今天涨什么"，而是"明天/下周/下月哪个板块将接力"）
- 推理链：因为宏观A+政策B+周期C → 预判板块D将占优

#### 阶段2：证据收集（Evidence）—— 找将涨信号
- 并行：sector(板块轮动接力) ∥ technical(形态预判) ∥ catalyst(催化日历+资金建仓) ∥ fundamentals(估值修复+业绩预增)
- 每个agent复用对应技能（sector-rotation-detector/event-driven/sentiment-reality-gap等）
- 输出：**每只候选票的"将涨信号"清单**（非0-100分，而是：信号类型+强度+触发条件）
  - technical：回踩缩量企稳/区间收敛待突破/底部结构
  - catalyst：未来催化日历+主力净流入未拉升+龙虎榜机构建仓
  - sector：板块接力跟风补涨票（龙头涨停→今天没涨的跟风）
  - fundamentals：超跌估值修复+业绩预增

#### 阶段3：推理验证（Reasoning）—— 综合演绎
- governor（或新建 reasoning agent）
- 输入：阶段2各agent的"将涨信号" + 阶段1方向预判
- 输出：**每只票的完整推理链**（A板块轮动+B资金流入+C形态回踩+D催化未兑现→E票未来N天有上涨潜力）
- 推理接力：每个agent的预判被governor综合，形成"因为...所以..."的演绎

#### 阶段4：潜力锁定（Lock）—— 选票+操作卡
- governor + risk-portfolio
- 输出：**未来时间段潜力TopN + 触发时间窗 + 买入区间 + 止损 + 止盈**
- 不再"回测证伪踢出"，而是"预判逻辑强度+风险收益比"排序

#### 阶段5：跟踪兑现（Track）—— 验证+反馈
- 新建 scripts/forecast_tracker.py
- 记录每次预测的票+时间段+预判逻辑
- 未来N天后回看是否真涨，计算命中率
- 用命中率反馈改进预判模型（Brier score 已有接口 in prob_path.py）

### 报告重构：推理链驱动

输出 `output/{asOf}_未来潜力预判_{周期}.md`：
1. **预判方向**：未来N天占优风格/顺风板块/接力方向（附宏观推理）
2. **潜力票清单**：每只票附完整推理链（A→B→C→D→E）
3. **未来催化日历**：哪些事件将兑现
4. **板块轮动图**：今天热点→明天接力方向
5. **操作卡**：触发时间窗+买入区间+止损+止盈
6. **预测跟踪表**：上次预测兑现情况

## 验证方式

1. 跑 future-picks 波段周期（1-2周），验证：
   - TopN 是"今天没涨/未透支 + 有将涨信号"的票，非当日涨停榜
   - 每只票有完整推理链（A→B→C→D→E）
   - 报告含预判方向+催化日历+操作卡+跟踪表
2. 预测后跟踪：未来1-2周回看推的票是否真涨，命中率量化
3. 与旧 short-term-picks 对比：旧的推已涨，新的推将涨
